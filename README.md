# 险恶疑航 · Feed the Kraken 在线版

5-11 人隐藏身份推理桌游《险恶疑航》（Funtails 出版）的在线多人实现。
服务端权威规则引擎，完整基础版规则，支持本机/局域网/公网联机。

```
忠诚水手 → 驶向蓝湾（东）
海盗     → 骗入绯红湾（西）
邪教     → 召唤海妖（北）/ 献祭邪教主
```

## 快速开始（Windows）

```
双击 start.bat
```
首次运行自动安装依赖并构建（约2-5分钟），之后启动只需数秒。启动后：

- 本机：http://localhost:3000
- 局域网：http://你的内网IP:3000（如 http://192.168.1.5:3000）
- 公网：见 `deploy/PUBLIC_NETWORK.md`（附 Cloudflare Tunnel 一条命令方案）

## 手动安装（macOS / Linux / 高级用户）

前置要求：Node.js ≥ 20（内置 SQLite，无需其他数据库）。

```bash
npm install                 # 安装依赖
npm run build               # 构建引擎/服务端/前端
npm start                   # 启动服务（端口 3000）
npm test                    # 运行全部测试（引擎72项 + 服务端E2E 6项）
```

### 环境变量（复制 .env.example）

| 变量 | 默认 | 说明 |
|---|---|---|
| PORT | 3000 | 监听端口 |
| HOST | 0.0.0.0 | 监听地址；127.0.0.1=仅本机 |
| FTK_DB | ./data/ftk.db | SQLite 存档路径 |
| FTK_ALLOWED_ORIGIN | * | 跨域来源；公网建议设为具体域名 |
| FTK_RATE_COMMAND | 30 | 每座位每10秒命令数上限 |
| FTK_BOT_DELAY_MIN/MAX | 400/1200 | （已弃用自动机器人，保留兼容） |

## Docker 部署

```bash
docker compose up -d --build
```
- 自动构建前端+后端，数据持久化在 `ftk-data` 卷
- 健康检查：`docker inspect --format='{{.State.Health.Status}}' <容器名>`
- 日志：`docker compose logs -f`

## 机器人（调试功能）

大厅中房主可点击 **🤖 添加机器人** 填满空位，一人即可开局调试。
- 对局内行动面板上方有 **代打切换条**：在"自己"和各机器人之间切换
- 切到机器人后可看到它的手牌、角色牌与待办操作，直接替它行动
- **边界**：代打仅限机器人座位。真人玩家的秘密信息（阵营/手牌/未亮角色）永远不会暴露给房主

## 对局恢复与备份

- 刷新页面/断网：同一浏览器自动恢复座位（会话凭据存本地）
- 服务器重启：对局自动从 SQLite 恢复（房间、进度、日志、身份全部保留）
- 备份：复制 `packages/server/data/ftk.db` 一个文件即可；恢复时放回原路径再启动
- 存档版本：`SAVE_VERSION = 3`（跨版本不保证兼容，升级前请备份）

## 项目结构

```
packages/
  engine/   规则引擎（纯 TS，确定性状态机，可注入随机源）+ 72 项规则测试
  server/   Express + Socket.IO + SQLite（node:sqlite），会话/房间/投影/限速 + 6 项 E2E
  client/   React + Vite 中文界面（大厅/棋盘/行动面板/日志/聊天/代打）
docs/       规则笔记、覆盖矩阵、资料原文
deploy/     公网部署指南、cloudflared
```

### 架构原则

- **服务端权威**：客户端只提交命令意图；所有随机、结算、信息过滤都在服务端
- **视图投影**：每个玩家只收到 `buildPlayerView(其座位)` 的输出，秘密数据不进网络响应
- **规则引擎独立**：`@ftk/engine` 不依赖网络/数据库，可独立测试；随机通过 Rng 接口注入，测试用固定种子
- **同一权威通道**：真人、机器人（代打）命令走完全相同的校验/幂等/串行化路径

## 已知限制

1. **地图数据**：短航程地图由用户提供的官方照片转录（行动格分布与官方组件数完全吻合）；长航程拓扑来自社区逆向数据并经照片结构核对。两者均标记 dataStatus='unverified'，建议与实体板做一次逐格比对。
2. 规则书未明说的 10 处裁决（如醉酒平局、通灵者时机）按惯例实现并记录于 `docs/RULES_NOTES.md` §9。
3. 不支持观战、语音、AI 智能机器人（代打为简单策略，主要供调试）。

## 测试


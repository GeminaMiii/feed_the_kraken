# Design

## Visual Theme

**عاصفة في عرض البحر، ليلًا.** كل شيء مغمور في حبر بحري شبه أسود. لا شيء مضيء إلا ما يحمل معنى: ثلاث ضياءات فصائل على الأفق، ووميض برق نادر يكشف ما لا تريد رؤيته.

الوضع الداكن ليس خيارًا — هو المنتج. لا يوجد وضع فاتح.

**السبب المادي:** الجلسة تحدث ليلًا حول طاولة، الجوال مقلوب أغلب الوقت، والشاشة تُرفع لثوانٍ. الأبيض الساطع يفضح صاحبه ويكسر الجو.

## Color

### Strategy

**كحليٌّ بحريٌّ ملتزم (Committed navy).** القاعدة اللونية زرقاءُ عميقةٌ حقيقية — لا رماديٌّ محايد. الكروما ترتفع مع الإضاءة كما يفعل الماء: العمق يبتلع اللون والسطح يعكسه.

اللون المشبع الحادّ محجوز للفصائل الثلاثة. السماويّ البحريّ (`--cyan`) هو اللمسة التفاعلية الوحيدة، وهيؤه (205) يبعده عن أزرق البحّارة (242) فلا يُقرأ إشارةَ فصيل.

القاعدة الحاكمة: **إذا رأيت لونًا مشبعًا حادًّا، فهو يعني فصيلًا.**

### Tokens

```css
:root {
  /* أعماق المحيط — كحليّ بحريّ */
  --ink-900: oklch(0.16 0.045 235);  /* قاع — خلفية الصفحة */
  --ink-800: oklch(0.21 0.050 234);  /* أسطح */
  --ink-700: oklch(0.27 0.052 233);  /* أسطح مرتفعة */
  --ink-600: oklch(0.35 0.050 232);  /* حدود */
  --ink-500: oklch(0.45 0.046 230);  /* فولاذ بارد — حدود بارزة وأيقونات */

  /* ضباب البحر — أبيضٌ باردٌ مائلٌ للأزرق.
     النسب مُقاسة مقابل ink-700، أفتحِ سطحٍ يحمل نصًّا — لا مقابل الخلفية وحدها. */
  --mist:     oklch(0.96 0.010 215);  /* نص أساسي — 13.4:1 */
  --mist-dim: oklch(0.80 0.022 215);  /* نص ثانوي —  8.1:1 */
  --mist-mut: oklch(0.68 0.028 215);  /* نص خافت  —  5.2:1 */

  /* سماويٌّ بحريّ — لمساتٌ تفاعلية فقط (تركيز، تمرير، نبض) */
  --cyan: oklch(0.75 0.12 205);       /* 7.0:1 */

  /* الفصائل — إشارات دلالية */
  --sailor:  oklch(0.72 0.16 242);   /* بحّار · شرق · 6.1:1 */
  --pirate:  oklch(0.68 0.175 22);   /* قرصان · غرب · 4.7:1 */
  /* الطائفة صوتان لا صوتٌ واحد */
  --cult:    oklch(0.81 0.16 88);    /* قائد الطائفة · شمال · 8.2:1 — ذهبيّ */
  --cultist: oklch(0.72 0.16 310);   /* تابعٌ مُحوَّل — بنفسجيّ · 5.7:1 على ink-700 */

  /* مكوّنٌ ماديّ لا إشارةُ فصيل: الورقة الصفراء على الطاولة، ونقاط السِّيَر،
     والتنبيهات المهمّة. منفصلٌ عن --cult ولو تطابقا اليوم. */
  --card-yellow: oklch(0.81 0.16 88);

  /* نجاحٌ وحياة، لا إشارةَ فصيل. كان مشتقًّا من --cultist فانفصل عنه. */
  --sea-green: oklch(0.74 0.16 148);

  /* البرق — للوميض فقط، ليس لونًا للعلامة */
  --flash: oklch(0.93 0.05 225);
}
```

**ممنوع في هذه اللوحة:** الأزرق النيونيّ الفاقع، السماويّ المفرط التشبّع، والألوان الكرتونية. الهيؤات محصورة في 205–242 **للقاعدة الباردة** (الأسطح والنصّ والتفاعل)؛ أما الفصائل فتخرج عنها عمدًا لأنها إشارات.

> **البنفسجي:** كان ممنوعًا في نسخةٍ سابقة. أُدخل بقرار المالك ليكون لون
> **أتباع الطائفة** (هيؤ 310) — لا الطائفةِ كلّها. القائدُ يبقى ذهبيًّا.
>
> **لماذا لونان للطائفة؟** القائدُ شخصيةٌ واحدة تُوزَّع في البداية، والأتباعُ
> لاعبون يُحوَّلهم أثناء المباراة. الفرقُ في الدور فرقٌ في الإشارة: مَن يرى
> اللوحَ يعرف فورًا مَن يقود ومَن حُوِّل.
>
> التحفّظ الأصلي — أن يزاحم اللونُ الجديد إشاراتٍ قائمة — عولج بفصل رمزين:
> `--card-yellow` (الورقة الصفراء، مكوّنٌ ماديّ) و`--sea-green` (النجاح والحياة).
> فلا يتغيّر أيٌّ منهما حين تتغيّر ألوانُ الفصائل.

### Usage rules

- **زر الإجراء الأساسي:** خلفية `--mist` صلبة، نص `--ink-900` (17.3:1). لا تدرّج، لا توهج. الثقة من التباين لا من اللمعان. التمرير يقلبه إلى `--cyan`.
- **زر ثانوي:** شفاف بحد `--ink-500`، وحدُّه يصير `--cyan` عند التمرير.
- **لا ذهبيّ ولا نحاسيّ كلون واجهة** — يتصادم مع أصفر الطائفة ويفسد الإشارة.
- **حلقة التركيز:** `--cyan` بسماكة 2px مع `outline-offset: 2px`. مرئية دائمًا، لا تُزال أبدًا.
- **الفصيل لا يُنقل باللون وحده أبدًا** — دائمًا لون + رمز + اسم نصي. حين يُلوَّن اسمُ فصيلٍ داخل جملة، فاللونُ تأكيدٌ لكلمةٍ تُسمّيه أصلًا (شرط عمى الألوان محفوظ).

## Typography

### Families

| الدور | الخط | ملاحظة |
|---|---|---|
| عناوين | **Alexandria** | هندسيّ حديث، حروفه مفتوحة وواضحة عند الأحجام الكبيرة |
| واجهة ونص | **IBM Plex Sans Arabic** | أعلى وضوح للفقرات الطويلة وللأحجام الصغيرة على الجوال |
| سرد فقط | **Aref Ruqaa** | محجوز حصريًا لاقتباسات "دفتر القبطان" |

محور التباين: هندسيّ عريض (600–700) × إنسانيّ عاديّ (400–500). ثلاثة أصوات، لكل واحد وظيفة لا يتعداها.

> **سبب استبدال Reem Kufi:** حروفه المنحوتة الزاويّة جميلة كنقش، لكنها تُبطئ القراءة
> في العناوين الطويلة وفي النصّ المشكول. Alexandria يحتفظ بالحضور ويكسب الوضوح.

### Scale

```css
--fs-display: clamp(2.6rem, 7vw, 5.2rem);   /* السقف 5.2rem — أقل من حد الـ6rem */
--fs-h1:      clamp(2rem, 4.5vw, 3.2rem);
--fs-h2:      clamp(1.5rem, 3vw, 2.2rem);
--fs-h3:      1.35rem;
--fs-body:    1.0625rem;  /* 17px — الخط العربي يحتاج جسمًا أكبر من اللاتيني */
--fs-sm:      0.9375rem;  /* 15px — لا ينزل تحته نصٌّ يُقرأ */
```

### Arabic-specific rules

- **`letter-spacing` يبقى `0` في كل النصوص العربية.** الخط العربي متصل — التتبّع السالب يكسر وصلات الحروف. (قاعدة التتبّع السالب في الأدلة الغربية لا تنطبق هنا.)
- `line-height`: **1.95** للنص الجسم، **1.85** للأسطر الشعرية القصيرة، **1.42** للعناوين.
  الحركاتُ والنقاطُ العربية تحتاج فراغًا رأسيًا أكبر بكثير من اللاتيني.
- المسافة بين الفقرات: `0.85em` (`p + p`) — أقلّ من سطرٍ كامل كي تبقى الفقراتُ كتلةً واحدة.
- عرض السطر: **48–54ch** للنص الطويل (أضيق من الـ65ch اللاتينية؛ الكلمة العربية أقصر).
- `text-wrap: balance` على العناوين، `pretty` على الفقرات.
- الوزن: **400** للنص (لا 300 — الأوزان الرفيعة تُفقد النقاطَ والحركات على الشاشات الداكنة).

## Layout

- **RTL أصلي.** خصائص منطقية حصرًا (`margin-inline-start`, `padding-block`, `inset-inline-end`) — لا `left`/`right` فيزيائية.
- شبكة استجابة بلا نقاط توقف حيث أمكن: `repeat(auto-fit, minmax(280px, 1fr))`.
- نقاط التوقف للفحص: **375 · 768 · 1024 · 1440**.
- **البطاقات ليست الحل الافتراضي.** خطوات "كيف تلعب" مبنية كفصول متتابعة بترقيم زمني حقيقي (تسلسل الجولة)، لا كشبكة بطاقات متطابقة.
- الحواف: البطاقات **12px**، الأزرار **10px** أو حبّة كاملة. لا شيء فوق 16px.
- **ممنوع:** حد جانبي ملوّن (`border-inline-start` سميك)، بطاقات متداخلة، نص بتدرّج لوني.

## Motion

| الغرض | المدة | التسهيل |
|---|---|---|
| تغذية راجعة (hover، ضغط) | 150–200ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| دخول عنصر | 400–600ms | expo.out |
| مرتبط بالتمرير | مربوط بالمؤشر | `scrub: 1` |
| وميض البرق | 80ms ظهور / 400ms خفوت | حاد ثم أُسّي |

**القواعد:**
- الحركة مربوطة بمعنى في اللعبة (بطاقة تُرمى، سفينة تتحرك، مسدس يُكشف) — لا حركة زخرفية.
- التمرير يُثبّت مشهدًا واحدًا فقط في الصفحة كلها. التثبيت المفرط يقاتل التمرير الطبيعي ويؤذي الجوال.
- المحتوى **مرئي افتراضيًا**؛ الحركة تحسّن ولا تُشترط. لا يُخفى محتوى خلف كلاس انتقال.
- `prefers-reduced-motion: reduce` → البرق يصير تلاشيًا هادئًا، الحركات المرتبطة بالتمرير تصير ظهورًا فوريًا، وحلقة العرض ثلاثي الأبعاد تتجمد على إطار واحد.
- **لا وميض يتجاوز 3 ومضات/ثانية** (أمان الصرع).

## 3D / WebGL

**النطاق:** الصفحة الرئيسية (`index.html`) فقط. لا WebGL في `player.html` أو `narrator.html` — تلك واجهات عمل تحت ضغط.

**المكتبات محلية** في `public/vendor/` (three 0.185.1 · gsap 3.15.0) — لا CDN، لأن الجلسات تحدث على شبكة محلية قد تكون بلا إنترنت.

**بوابات الأداء:**
- `devicePixelRatio` مقيّد عند **1.75**
- المطر ≤ **2500** جسيم
- شبكة البحر ≤ **128×128** قسمة
- لا معالجة لاحقة (postprocessing) — التوهج يُنفَّذ بالخامة لا بمرور إضافي
- تُوقف حلقة العرض عند `visibilitychange` وعند خروج المشهد من الإطار

**البديل:** الجوال وأي جهاز يفشل في اختبار القدرة → لا يُحمَّل Three.js إطلاقًا. طبقات CSS متوازية بنفس التركيب تعطي ٦٠ إطارًا مضمونة. البديل يُبنى أولًا، والـWebGL يُضاف فوقه كتحسين.

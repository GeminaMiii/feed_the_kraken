# 险恶疑航 · 本次界面需求（可执行版）

这些条目是根据 `改动1.docx`、现有页面和本次反馈整理后的实现验收标准。

1. **视觉语言**：使用深海蓝、古典金和暖象牙色；标题与卡面规则使用中文衬线字体，按钮、徽章和状态色保持克制。卡片必须使用独立卡面容器、清晰边框、完整标题和正文，不得把整张卡图裁剪后当作另一张卡。
2. **角色入口**：左下角固定提供“我的角色”“游戏规则”“全部卡牌”三个并列入口。角色牌不放在航海图下方常驻；点击“我的角色”才打开私密角色牌与技能说明。
3. **角色揭示动画**：首轮进入游戏时显示牌背，点击后翻转为本人角色；关闭时以缩放/位移动画收回玩家区。动画必须尊重 `prefers-reduced-motion`，且刷新页面不能反复遮挡已确认的角色牌。
4. **卡牌资料库**：角色、导航、邪教仪式分栏展示；每个卡片都是独立可点击目标，点击后打开可滚动的大图预览，支持 Escape、遮罩点击和移动端操作。导航和仪式卡必须分开，不得继续使用合并裁剪图。
5. **信息边界**：未公开的角色、阵营、手牌和仪式目标不得进入其他玩家视图；领航牌只显示给对应操作玩家。公开角色才允许在玩家列表中点击查看。
6. **可玩性**：任命、哗变、抽牌、弃牌、领航员选择、导航效果、停职和终局均应能通过现有状态机完成；操作按钮只能发送当前 pending 所允许的命令，并在失败时显示服务器规则错误。
7. **响应式**：桌面端保持玩家区/航海图/日志三栏；窄屏端按玩家区、航海图、行动区、日志顺序堆叠，卡片横向滚动或网格缩放，不得溢出视口。
8. **资源策略**：优先复用已有官方角色原画；图片生成只为缺失的独立导航/仪式视觉补充，生成结果保存为单文件并通过 `loading=lazy` 引用，额度受限时不得重复生成或用裁剪伪造。
